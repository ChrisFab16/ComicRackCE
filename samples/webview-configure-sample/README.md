# WebView Configure sample (SPA source)

Source for the built-in `WebConfigureSample` plugin UI.

```bash
npm run build
```

Copies `src/` → `ComicRack/Output/Scripts/WebConfigureSample/ui/dist/`.

Authors can replace this with Vite/React later; Host API bridge contract is in `src/host-bridge.js` and `specs/006-plugin-webview-host/contracts/host-api-v1.md`.
