# Quickstart: kind=web plugins

## WebKindSample (no Python)

1. Ensure Debug build is current; sample is under EXE `Scripts/WebKindSample/` and/or copy to `%AppData%\cYo\ComicRack Community Edition\Scripts\WebKindSample\`.
2. Restart ComicRack.
3. Preferences → Scripts: package **Web Kind Sample**; command **Web Kind Sample** → **Configure**.
4. SPA should load via Host API v1 (same bridge as 006).
